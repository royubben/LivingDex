# Sprite / Spawn / Form Audit v3.6.15

- Restored the previous `0502_Dewott.webp` asset for Hisuian Dewott.
- Removed Rockruff Dusk (`rockruff|dusk|744|main`) from the LivingDex.
- Minior meteor/colors now use the bundled local sprite assets.
- Furfrou trims now use the bundled local Project Pokémon/Home-derived assets.
- Mimikyu, Tapu Koko, Tapu Lele, Tapu Bulu, Tapu Fini, Zeraora, Meltan, Melmetal and Oinkologne now use their bundled local sprites instead of the PokeAPI remote override.
- Magikarp Jump and Gyarados Jump cards now display only the actual pattern/variant name.
- Magikarp Jump/Gyarados Jump natural spawn data is suppressed in the UI; these patterns are obtained through the Cobblemon-specific fishing/evolution mechanics. Cobblemon documents the patterns and their obtainment/chance-biome information on its Unique Forms page.
- Box headings are now coupled as `Region + box number`, e.g. `Kanto 1`.
