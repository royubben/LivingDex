# Cobblemon LivingDex V2.0.38 — Native PokéSnack Maker

## Update
The PokéSnack Maker is now implemented natively inside the Trainer OS.

- No iframe or external page is used.
- Uses the app's bundled Cobblemon 1.8 species data.
- Pokémon search by name or Pokédex number.
- Shows target sprite, types, egg groups and EV yield.
- Builds three seasoning slots.
- Includes type, egg-group, EV, rarity, shiny and utility bait seasonings.
- Generates target-specific recipe suggestions.
- Recipes can be loaded directly into the three slots.
- Mobile-responsive layout.

## Important
The recipe matcher is based on the Cobblemon source data bundled with this app. Exact in-game spawn odds can still vary with server datapacks, spawn pools and environmental conditions.
