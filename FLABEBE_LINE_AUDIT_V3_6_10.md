# Flabébé Line Audit — v3.6.10

## Cobblemon forms verified

Cobblemon has six flower variants for the Flabébé line in this project: Red, Yellow, Orange, Blue, White, and Cobblemon Pink. The Pink form is a Cobblemon-specific form.

## LivingDex order

The special `Flabebe lijn` page now contains 18 entries in this exact order:

1. Red Flower: Flabebe → Floette → Florges
2. Yellow Flower: Flabebe → Floette → Florges
3. Orange Flower: Flabebe → Floette → Florges
4. Blue Flower: Flabebe → Floette → Florges
5. White Flower: Flabebe → Floette → Florges
6. Cobblemon Pink: Flabebe → Floette → Florges

The Red Flower entries intentionally reuse the normal `|base|...|main` IDs, so the main LivingDex and the special page share one caught-state/database identity for the default/red form.

Pink uses the bundled Cobblemon-specific sprites already present in the package.
