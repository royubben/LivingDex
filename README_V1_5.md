# Cobblemon LivingDex V1.5.4

## Daily Dex
- Dedicated Daily Dex tab.
- Monthly calendar with previous/next month navigation.
- Future dates show a question mark.
- Completed, missed, and current days use distinct clean visual states.
- Daily Pokémon remains clickable for history viewing.
- Current streak, best streak, total completed, monthly completion and tracking start are shown.
- Daily history is stored inside the existing training JSON save, so no new Supabase migration is required.
- Daily Dex selection excludes Legendary, Mythical, Ultra Beast, Paradox and Restricted entries.

- V1.4.2 save system and account sync.
- Progress, Milestones, Training, Players and Leaderboards.
- Evolution Training fixes.
