# Sprite source notes — v3.6.11

## Flabébé line

Cobblemon has Red, Yellow, Orange, Blue, White and Cobblemon Pink. Pink is a Cobblemon-specific form.

The standard Red Flabébé and Red Florges local base sprites were corrected in this build because the previous bundled base assets were visibly blue. Pink uses the bundled Cobblemon-specific sprites.

## Showdown HOME sources verified

Showdown HOME currently exposes Furfrou trims, Unown letters, Minior meteor/core colors, and the official Flabébé/Floette/Florges color variants.

Source: https://play.pokemonshowdown.com/sprites/home/

## Arbok

The 21 Arbok pattern assets are now normalized to 256x256 transparent canvases so the Pokémon stays aligned across cards.
