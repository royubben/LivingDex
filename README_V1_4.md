# Cobblemon LivingDex V1.4

## New
- Progress dashboard expanded with collection statistics, Daily Dex, generation completion, type completion and special collections.
- Daily Dex streak with current streak, best streak and public player visibility.
- Milestones page with earned/locked badges.
- Training overview with rank and aggregate statistics.
- Players can see daily streaks and earned badges on public profiles.
- Leaderboard: Most Pokémon Caught and Daily Streak.

## Supabase
Run `V1_4_DAILY_STREAK_MIGRATION.sql` once in the Supabase SQL Editor for the Daily Streak leaderboard.


V1.4.1 hotfix: Daily Dex excludes Legendary/Mythical/Ultra Beast/Paradox/Restricted entries; Daily completion follows current caught state; Evolution Training now uses direct Cobblemon pre-evolution pairs and displays the exact target Pokémon.
